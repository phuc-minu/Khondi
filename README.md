# Khondi

AI-powered vacation planning and optimization SaaS.

**Status:** Planning and architecture review. Product and implementation plans require owner approval before code changes.

Working stack: Python backend, PostgreSQL, Next.js (React + TypeScript), with OpenStreetMap and OpenRouteService behind swappable provider interfaces. Primary demonstration and evaluation destination: New Orleans.

This repository's AI workflow governance and role instructions are being proposed for review. Nothing is authorized to auto-merge or deploy.
